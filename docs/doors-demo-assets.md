# Doors demo artwork

Generated with the built-in image generation tool for the local `/doors-demo/` prototype. Original reference: the user's Gemini vault concept. Game controls, door opening, prizes and settlement are live code; the images contain no interface or lettering.

## Final environment prompt

Create a premium cinematic 3D game environment background, wide landscape 16:9. Symmetrical underground billionaire treasury hall with massive weathered stone arches and pillars along left and right edges, thin horizontal warm gold light strips along walls, subtle security cameras in upper corners, teal cyan atmospheric light from behind a central empty recessed wall, worn stone floor foreground. The central 70 percent is dark shadowed plain stone, reserved for a game board overlaid in code. Luxurious moody depth, realistic materials, polished casual treasure hunt game aesthetic. No doors, no vault cabinet, no interface, no numbers, no text, no logos, no people. Full bleed single environment.

## Final door prompt

Create a single game sprite texture: front-on orthographic closed square treasure vault door, centered and filling canvas edge to edge with absolutely no margins. Aged dark walnut wood planks, thick beautifully detailed golden brass rectangular frame with rivets, heavy dark steel hinge straps at left, intricate round brass combination lock in center with short horizontal bolt and small rounded handle to right, two vertical brass reinforcement rails. Thick outer dark gunmetal square frame with tiny gold rivets. Cinematic stylized realistic 3D render, rich tactile material, warm gold edge highlights, premium treasure hunt game. Perfectly square straight-on, no perspective. No lettering, no numbers, no UI, no surrounding scene.
